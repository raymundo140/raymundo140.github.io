The semester combined AI coursework with hands-on embedded development and academic work around emerging computing hardware for intelligent systems.

## Coursework

## Dual-Elevator Embedded Control Project

The main project for Advanced Embedded Systems was a dual-cabin, five-floor elevator prototype controlled by an STM32 microcontroller. I designed and built the physical system in SolidWorks and 3D printing, and implemented the embedded controller in C using a non-blocking architecture based on concurrent finite-state machines, Hall-effect safety sensing, PWM servo control, and a greedy request-scheduling algorithm assigning floor requests to the available cabins.
