### Advanced Embedded Systems

Advanced Embedded Systems focused on real-time control and embedded-system design. The main project for the course was a dual-cabin, five-floor elevator prototype controlled by an STM32 microcontroller. I designed and built the physical system using SolidWorks and rapid-prototyping methods, including 3D printing, and implemented the embedded controller in C using a non-blocking architecture based on concurrent finite-state machines.

The system included two independently controlled elevator cabins across five floors, concurrent finite-state machines, non-blocking real-time control, PWM servo control, Hall-effect safety sensing, floor and request handling, a greedy request-scheduling algorithm, STM32-based embedded control, mechanical design in SolidWorks, and 3D-printed components. The project required coordinating mechanical design, electronics, sensing, control logic, and embedded software in a complete working prototype.

Rather than controlling the system with blocking delays or a single sequential loop, I implemented concurrent finite-state machines so that both cabins and the supporting control logic could operate independently while sharing system resources. Hall-effect sensors were used for position and safety feedback, PWM-controlled actuators handled cabin movement, and I implemented a greedy request-scheduling algorithm to assign pending floor requests to the available elevator cabins.
