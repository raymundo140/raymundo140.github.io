## Overview

Built a hardware–software tractor simulator using a Terasic DE10-Lite FPGA and Unity. Physical controls on the FPGA drove a virtual tractor, while simulation telemetry was sent back to the board for live hardware display.

## FPGA

VHDL logic handled:
- Switch and push-button inputs.
- Command generation.
- Serial communication.
- Telemetry decoding.
- Seven-segment display output.

## Unity

C# code received command bytes and mapped them to tractor motion inside a real-time 3D environment.

## Bidirectional Telemetry

Unity transmitted the crop counter back to the FPGA. The board decoded the value and displayed it on physical seven-segment displays while the simulation ran.

## My Contribution — Processor Integration

The final version added accelerometer-based steering and Assembly routines for processor-level input handling and command generation.

## Result

The final prototype closed the loop between physical hardware and simulation: FPGA inputs controlled the Unity tractor in real time, and simulation state returned to the FPGA for physical display.
