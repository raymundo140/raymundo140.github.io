## Overview

This project was developed for the Embedded Systems Applications Design course at the University of Seoul. The objective was to design, fabricate, program, and validate a complete five-floor dual-elevator automation prototype combining mechanical design, embedded electronics, actuator control, user input, scheduling logic, safety mechanisms, and real-time system monitoring.

## System Architecture

The system was built around an STM32 NUCLEO-G474RE microcontroller controlling two independent elevator cabins. Each elevator was actuated by an FS90R continuous-rotation servo through a rope-and-drum mechanism. A 4x4 matrix keypad provided the operator interface for entering origin and destination floors, while magnetic sensing was incorporated at shaft limits to prevent mechanical overtravel. UART communication exposed internal system states and scheduling activity through a PC terminal for debugging and demonstration.

The embedded software was implemented in C using STM32 HAL libraries and STM32CubeIDE, organized into separate functional layers for keypad scanning, servo actuation, request scheduling, and elevator execution. Rather than directly coupling user input to motor commands, keypad events generated origin-destination requests that were stored in a centralized request queue, with a scheduling layer determining which elevator should service each request.

## Scheduling Algorithm

A deterministic greedy scheduling algorithm was implemented for elevator assignment. When a request was pending and an elevator was available, the scheduler evaluated candidate elevators using a scoring function based primarily on distance to the pickup floor, elevator availability, and a smaller directional preference — the elevator with the lowest score received the request. This provided a computationally lightweight scheduling strategy suitable for a resource-constrained microcontroller supporting two independently operating elevators.

Each elevator was represented using its own state data (current floor, pickup floor, drop-off floor, direction, job phase, state-transition timestamp, busy status), with motion controlled through a state-machine architecture spanning idle, moving, and door states across pickup and drop-off job phases.

## Actuation and Mechanical Design

Servo actuation used hardware PWM generated by separate STM32 timer channels — Elevator 1 through TIM3 Channel 4 on PB1, Elevator 2 through TIM20 Channel 3 on PC8 — with both servos operated at 50 Hz. Because continuous-rotation servos exhibited different neutral points and motion characteristics, individual calibration profiles (neutral, upward, downward, deadband) were implemented, with PWM commands clamped to safe limits and deadband filtering reducing unintended drift.

The 4x4 keypad was implemented through GPIO row-column scanning (four rows as outputs, four columns as pull-up inputs), converting valid origin-destination pairs into scheduler requests. Mechanical components were designed in SolidWorks and fabricated through FDM 3D printing, producing two elevator cabins and a unified five-floor supporting structure with truss reinforcement for stability. Logic and actuator power were separated — the STM32 was powered through USB while the two servos used an external supply with a shared ground reference — reducing load on the microcontroller board and providing stable PWM control.

## Results

The completed system integrated the STM32, keypad, external servo power, dual elevator structure, and serial monitoring interface into a working physical prototype, demonstrating embedded system architecture, deterministic scheduling, finite-state-machine design, hardware timer/PWM configuration, actuator calibration, and full hardware-software integration in a multi-actuator automation system.
