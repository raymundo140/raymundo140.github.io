## Overview

Built a Raspberry Pi-based smart-agriculture prototype at Beijing Institute of Technology that monitored environmental conditions, controlled irrigation and ventilation automatically, and exposed live sensor data through a web dashboard.

## System

A Raspberry Pi acted as the central controller, collecting data from distributed environmental sensors and applying automation logic to physical actuators.

The control loop followed a simple architecture: Sense → Process → Decide → Actuate → Monitor.

When environmental conditions crossed the configured thresholds, the platform could trigger physical responses such as irrigation or ventilation.

## Web Interface

A browser-based dashboard displayed live environmental data and provided a single view of the physical system.

## Result

The project connected sensing, edge computing, actuator control, automation, and web monitoring into one working cyber-physical prototype.
